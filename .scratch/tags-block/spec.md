# GET多行标签兼容修复

来源：2026-09-20知识库返工真实只读检查发现，插件来源使用 tags 多行列表，当前程序只支持inline，导致168篇扫描整体拒绝。

用户结果：原有人工维护入口能够只读扫描插件生成的标准多行tags，同时维持未知格式拒绝、原件只读、无自动应用的现有边界。

验收：inline与同值block标签哈希一致；重复字段、混合缩进、空项、嵌套结构失败关闭；完整回归通过；真实168来源只读扫描可完成并如实报告差异，不为了无变化推进快照。

范围：修原扫描器的tags block形式及与inline共用的字符串解码（修复审查发现的转义哈希不一致），不引入YAML依赖、不泛化多行正文、不改来源、索引、接受快照、应用合同。
