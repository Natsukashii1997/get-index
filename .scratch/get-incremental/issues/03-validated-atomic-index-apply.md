# 03: 校验通过后原子更新 GET 索引

**What to build:** 把已经完成人工复核的增量记录合并进规范记录，动态生成索引页，并且只有检测基线仍有效、所有枚举与覆盖校验通过时才一次性更新来源层之外的索引；任何失败都不留下半更新状态。

**Blocked by:** 02: 为新增与关键变化生成保守复核记录.

**Status:** complete

**Execution:** complete

- [x] 应用前重新核对来源指纹；检测后来源发生变化时拒绝应用。
- [x] 合并后必须通过路径与 UID 唯一、来源覆盖、字段枚举、稳定主题、回链和隐私规则校验。
- [x] 所有索引计数、日期范围和快照日期从当前规范记录动态生成，不保留固定“168”或固定日期文案。
- [x] 无增量时不重写索引；生成或校验失败时不修改任一目标页，也不推进快照。
- [x] 自动测试在临时目录验证成功应用、幂等、并发变化和失败回滚；不得用真实 GET 制造测试来源。
